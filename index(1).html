Method & sources

Built with the data-cleaning and visualization workflow from EMERGE Textbook 1: Data Analysis, applied to real NASA GLOBE Observer Mosquito Habitat Mapper reports (via UF GeoPlan/GeoDI's Florida layer), live rainfall from Open-Meteo, and pond/lake locations from OpenStreetMap, combined the way the geoemerge package processes participatory science data. The map is limited to Alachua County. Any layer that can't be reached live falls back to a small labeled sample set so the site keeps working.
